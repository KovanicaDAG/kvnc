# kvnc Next-Steps Skeleton

Supporting files for the six follow-up items after the contract + tokenomics skeleton was integrated.

| Folder | Purpose |
|--------|---------|
| `01-host-and-storage` | Real `Host` implementation + storage key layout |
| `02-tests` | Tokenomics unit tests + contract test skeletons |
| `03-rpc-cli` | RPC method shapes + CLI subcommand stubs |
| `04-tokenomics-live` | Execution-hook to credit leaders & claim treasury |
| `05-docs` | Ready-to-use `CONTRACTS.md` |
| `06-examples-indexer` | Example flow + event topic constants |
| `AGENT_PROMPT.md` | Full instructions for the coding agent |

## How to use

1. Copy this whole folder into the kvnc repository root (or any convenient place).
2. Give the agent the prompt in `AGENT_PROMPT.md`.
3. Let it work through the six items in order.

Everything is deliberately incomplete on purpose — it is a skeleton, not finished production code.
