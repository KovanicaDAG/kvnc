## What's missing (Phase 18 plan)
1. **Delegation bond/unbond + commission**
   - `delegate(validator, amount)` → increase `validator.stake`
   - `unbond()` → queue with `unbonding_period` rounds
   - Reward share: `reward * (delegator_stake / total_staked) * (1 - commission_bps/10000)`
   - `withdraw()` after unbonding period complete
2. **Validator rotation at epoch**
   - `EPOCH_ROUNDS` (tunable, ~2M); rebuild committee from top N by stake
   - Stable indices (sort by pubkey)
3. **Slashing**
   - Evidence tx: double-sign (two blocks same round/author with valid sigs)
   - Fixed % slash (`SLASH_PCT_BPS=500` = 5%) + tombstone
4. **CLI commands** (`kvnc-cli`): `stake`, `unstake`, `delegate`, `claim-rewards`

## Exit criteria
- `delegate → wait rewards → unbond → wait → withdraw` e2e passes
- Epoch rotation changes committee deterministically
- Double-sign evidence triggers slash + tombstone
- All via deterministic `BTreeMap` / sorted selection (no `HashMap` ordering)

## Hard rules preserved
- `kvnc` only; no `kovanica-protocol` mix
- Tokenomics locked (90.2M cap, 10 KUNA initial, ×¾ decay, 2.05M era)
- Determinism: sort by `address` / pubkey; fixed seed where needed
- Resource target: 2-4 GB RAM
